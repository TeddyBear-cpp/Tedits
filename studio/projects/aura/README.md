# AURA+

A self-contained fictional luxury streetwear storefront. The deployed page is index.html; its bundled scripts, styles, photographs, fonts and favicons are stored alongside it. No ChatGPT Site is needed to run it.

Editable React/Vite source is in source/. To edit, run npm ci and npm run dev there. Run npm run build in source/ to regenerate the deployed files in this directory; the source folder is retained. The portfolio build publishes the runtime files and excludes source/.

The shopping bag is local to the browser. No payment or order service is connected. Fashion imagery is AI-generated.
