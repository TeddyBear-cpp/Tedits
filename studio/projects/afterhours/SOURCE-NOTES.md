# AFTERHOURS — fictional studio / v0

Design direction: original record-sleeve inspired editorial portfolio. No existing brand assets or customer claims. The vinyl is an interactive code-native illustration, not a product image or third-party brand asset.

Design Read: greenfield music producer portfolio; independent artists; warm editorial record-sleeve visual language. Visual variance 7, motion 4 (raised from 3 following feedback), density 5, asset dependence 3, fidelity 2. Limited animation concentrated on one disc; track list favors scanning; fictitious original identity.

Positioning: hero establishes atmosphere, collection previews track-list structure, licenses compare scope, contact closes. Laptop and phone viewing. Warm and unhurried. Two-column desktop hero becomes one column on mobile.

Tokens: charcoal #191a18, ivory #eae6db, muted #aaa99f, amber #e5a34c; rule #41423b. Disc shading derives neutral tints. Local Nimbus Sans Narrow Bold display and Nimbus Sans Regular body. Eight-pixel spacing base; square controls, round vinyl/play buttons; shadows reserved for record and floating controls. 180–240ms ease cubic-bezier(.2,.7,.2,1). Reduced motion respected.

Typography assets: dist/assets/display.otf; dist/assets/body.otf. Original wordmark is live type; no external logo or imagery.

v0 assumptions: illustrative sample titles, no real audio or fabricated prices. Beat filtering, playback and inquiry submission intentionally pending visual approval. Composition variants in Tweaks: Studio, Record sleeve, Listening room. Vinyl supports hover, tap toggle, and scroll. Motion pauses offscreen and in background tabs.

Verification: static code and local assets checked. Browser QA unavailable because the managed environment has no control-browser skill. No browser screenshot or cross-viewport execution claimed.

Motion correction: reduced-motion preferences determine the initial default. Explicit checkbox or record activation overrides that default. Enabling the checkbox starts continuous spin immediately. Subsequent OS preference changes do not reset a user choice.
