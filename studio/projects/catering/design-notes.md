# Olive & Ember Catering — website concept

Open `index.html` in a modern browser. No server or installation is needed. Fonts, styles, scripts and photographs are included locally.

For sharing, use the standalone `Olive-and-Ember-Preview.html` supplied alongside the source ZIP. It embeds all images, styles, scripts and fonts, so it also works offline.

## Included
- Original fictional brand and catering copy.
- Weddings, corporate catering, private gatherings, breakfast and brunch, and weekly meal prep.
- Three selectable sample menus; arrow keys, Home and End work in the menu tabs.
- Sample enquiry with occasion, head count, serving style, preferences, a summary and an edit action. No data is transmitted or stored.
- Mobile navigation, native accessible dialogs, visible focus states and reduced-motion support.
- Gentle one-time scroll reveals, image hover zoom and menu transitions.

## Design
