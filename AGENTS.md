# Collaboration preferences

## Answer questions before building

When the user's prompt includes a question, answer the question first. Then ask whether to continue with the proposed implementation and wait for the user's explicit go-ahead before building or changing implementation files. This applies even when the question appears alongside feedback or suggested changes.

Do not treat questions such as "is that fixable?" or "can you add/change/build this?" as permission to start building. Read-only investigation needed to answer the question is allowed.
