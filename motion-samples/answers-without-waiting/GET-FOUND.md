# Get found

Second standalone film, approved after the Answers sample. Remotion + original SVG; no website integration or deployment.

Six seconds (user authorised up to seven), 1080 × 1080, 60fps, silent H.264; the same brand palette and DM Sans / Syne as the first film. The first film remains four seconds.

## Sequence

- 0.00–0.80: a search symbol stretches into a search field.
- 0.73–1.53: “florist near me” types into the field.
- 1.57–2.38: three search results arrive with staggered spring settling.
- 2.32–3.12: the first result expands into a clear business website while the others recede. “Be found.” arrives word by word.
- 3.12–4.63: the featured result holds for reading.
- 4.63–5.88: the layout releases, results clear, and the search field returns to its original symbol.
- The compact search symbol matches across the seam. User revision: remove the orbiting ball, its trail and orbit guide from both films.

Generic illustrative results; the film does not represent real search rankings or promise a particular ranking.

## Rebuild and preview

`node render.mjs --get-found --stills` renders inspection frames.

`node render.mjs --get-found` renders `out/get-found-loop.mp4` and its poster.

`node --experimental-strip-types check-get-found.mjs` checks loop continuity and bounds.

Run the existing preview server, then open `http://127.0.0.1:8091/get-found.html`.
